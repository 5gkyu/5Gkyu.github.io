# ロジックパズル 要件定義

Halcyonの世界観（「寛容な共鳴」「温かい沈黙」「誰も無理をしない穏やかな関係」）に基づき、攻撃的・対立的な要素（嘘つき探し、勝敗など）を排除した、優しく穏やかな論理パズルです。

## 1. マトリックスパズル（現在の実装モード）

「席（1番〜N番）」と「持ち物」の2つの属性を、キャラクターに紐づけるマトリックス推理パズル。
提示された「手掛かり」をもとに、矛盾のない唯一の組み合わせを導き出します。

### ■ 基本仕様
- **人数の可変**: ロビー画面で **4人 / 5人 / 6人** から選択可能。
- **キャラクター**: A, B, C, D, E, F（人数に応じて変動。アイコン画像あり）
- **持ち物**: 懐中時計、万年筆、コンパス、花束、ギター、ベル（Halcyonの世界観に合わせたアイテム）

### ■ UI / UX
- **没入感のある全画面表示**: ゲーム開始時はヘッダーやサイドバーを非表示にし、パズルに集中できるフルスクリーンレイアウト。
- **ドラッグ＆ドロップ操作**: 画面下部の「プール」から、人物チップと持ち物チップをステージ（席）へドラッグして配置。ダブルクリックで解除可能。
- **思考プロセス（THINKING）表示**: 答え合わせ時に、プログラムがどのように推理して解を絞り込んだかを示す「推論ログ」をステップバイステップで表示。
- **メモ機能**: プレイヤーが自由に推理を書き込める広めのメモエリア（テキストエリア）を実装。
- **誤操作防止**: ページ全体でテキストのドラッグ選択を禁止（メモエリアのみ例外）。
- **ロビーからの設定変更**: 「パズルを開始する」前のロビー画面で、ヒントの種類の一括選択・解除が可能。
- **安全な問題生成**: ヒントの数が少なすぎる場合は開始ボタンを非活性化し、生成に時間がかかる場合（8秒以上）は自動でタイムアウトしてフリーズを防止。

### ■ 採用されているヒントの種類（全20種）
生成されるパズルのバリエーションを豊かにするため、以下のヒントが実装されています。ロビー画面からオン・オフの選択が可能です。

1. **席確定**: 「Aは〇番の席にいる」
2. **持ち物確定**: 「Aが持っているのは〇〇だ」
3. **席否定**: 「Aは〇番の席ではない」
4. **持ち物否定**: 「Aは〇〇を持っていない」
5. **左右関係**: 「AはBより左側にいる」
6. **隣接**: 「AとBは隣り合っている」
7. **持ち物隣接**: 「Aは〇〇を持つ人の隣にいる」
8. **すぐ左**: 「Aは〇〇を持つ人のすぐ左にいる」
9. **左側**: 「Aは〇〇を持つ人より左側にいる」
10. **席+持ち物**: 「〇番の席の人は〇〇を持っている」
11. **端**: 「Aはどちらかの端（1番か末尾）に座っている」
12. **非隣接**: 「AとBは隣り合っていない」
13. **間に1人**: 「AとBの間にはちょうど1人いる」
14. **間に2人**: 「AとBの間にはちょうど2人いる」
15. **挟まれる**: 「Aは、BとCの間に座っている」
16. **アイテム隣接**: 「〇〇を持つ人のすぐ右に、〇〇を持つ人がいる」
17. **アイテム非端**: 「〇〇は端の席にはない」
18. **距離比較**: 「AはBよりもCに近い」
19. **アイテム左側**: 「〇〇は〇〇より左側にある」
20. **アイテム非隣接**: 「〇〇と〇〇は隣り合っていない」

## 【今後の拡張アイデアパターンの控え】

### 2. 順序パズル（Order Quiz）
キャラクターを1位〜N位の枠（例：散歩の順番、到着した順など）に並べる基本的な形式。

### 3. グループ分けパズル（寄り添いのパズル）
「どのグループで一緒に行動したか」「誰と誰がペアになったか」を解き明かす形式。（例：お茶会のテーブル分け、スケッチのペアなど）

### 4. タイムラインパズル（時間のパズル）
「誰がいつその場所（図書館の奥の席、庭のベンチなど）を訪れたか」という、時間帯ごとの行動履歴を復元するパズル。

### 5. リレーパズル（贈り物のパズル）
「誰が誰に物を渡したか」「誰の隣に誰が座って輪を作ったか」という、循環構造や方向性のある繋がり（グラフ構造）を解き明かす形式。
