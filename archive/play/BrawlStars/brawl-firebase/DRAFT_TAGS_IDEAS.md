# ブロスタ ドラフト・ピック順別タグ定義＆戦術解説

ブロスタ（Brawl Stars）のガチバトル（エリート〜マスター帯）および競技シーン（BSC・公式大会）における **ドラフト（スネーク形式 BAN/PICK）のピック順・タイミング** に特化した詳細なタグ解説とアイデア集です。

---

## ドラフトの基本構造（スネーク形式）

```
[BANフェーズ] → [Team A: 1st] → [Team B: 2nd / 3rd] → [Team A: 4th / 5th] → [Team B: 6th (Last)]
```

---

## 1. ピック順・タイミング別タグ一覧

| タグ名 | 推奨タイミング | 役割・戦術的意図 | 代表キャラクター例 |
| :--- | :--- | :--- | :--- |
| **先出し安定（ファーストピック）** | 1st〜3rd | 相性差が小さく、明確なアンチが少ないため相手の出方が見えない段階でもノーリスクで置ける万能枠 | コレット、ジーン、マックス、ベリー、ガス |
| **OPピック（最優先確保）** | 1st | マップや現環境で突出して強く、BAN漏れした際に先攻が絶対に奪うべきパワーキャラ | クランシー、フランク、リリー、モーティス |
| **ブラフピック（誘導先出し）** | 1st〜2nd | あえて特定の弱点を見せ、相手にアンチを選ばせて後続のピックで嵌める罠枠 | フランク（相手にコレット/サージを誘発）、ブル |
| **カウンターピック（初手潰し）** | 2nd〜3rd | 相手のファーストピックに対して明確に対面勝ちできる返し手枠 | サージ（対タンク）、メイジー（対近接）、ベル（対長射程） |
| **コンボピック（ペアシナジー）** | 2nd & 3rd | 2体同時に取れる権利を活かし、強力な相乗効果を持つ2体編成を一気に成立させる枠 | バイロン＋アッシュ、キット＋ドラコ、マックス＋近接 |
| **フレックス（ポジション可変）** | 1st〜4th | ミッドもサイドもこなせるため、相手に編成の配置や戦術を読ませない枠 | チェスター、コレット、オーティス、タラ、ボウ |
| **弱点ケア（ラストピック対策）** | 4th〜5th | 相手の6手目（ラストピック）で出されそうなアンチ（アサシン・投げ等）を先読みして迎撃できる枠 | ゲイル、ジーン、シェリー、オーティス |
| **補完ピック（ピース埋め）** | 4th〜5th | 自チームに足りない要素（壁破壊、CC、火力、長射程など）を的確に補強する枠 | ブロック（壁壊し）、ルー（制圧）、コルト（火力） |
| **ラストピック特化（完封枠）** | 6th（Last） | 相手の3体にアンチが1体もいない時に出し、単体で試合を決定づける超有利枠 | モーティス、エドガー、エリザベス、ドラコ、チャック |
| **デナイアル（奪取ピック）** | 2nd〜5th | 自分が使うだけでなく、「相手に取られると崩壊する」ため先回りして奪うピック | チャック（強奪）、エリザベス（開けたマップ）、コレット |
| **BAN推奨（マストBAN）** | BAN時 | そのマップで対策不能な性能を持ち、後攻（または先攻で取れない場合）に絶対に禁止すべき枠 | クランシー、モーティス、チャック（強奪） |

## 2. ピック順別の詳細解説

### 1手目（先攻 1st Pick）
*   **求められる性能**: 「弱点の少なさ」「汎用性」「環境トップ性能（OP）」
*   **考え方**: 相手は残り2手で自由にカウンターを当てられるため、特定のキャラに極端に弱いキャラ（投げ・近接など）は厳禁。
*   **代表タグ**: `先出し安定` `OPピック` `フレックス` `ブラフピック`

### 2〜3手目（後攻 2nd & 3rd Pick）
*   **求められる性能**: 「相手初手へのカウンター」＋「2体でのシナジー形成」
*   **考え方**: 相手の初手を潰しつつ、味方2体で「タンク＋ヒーラー」「加速＋アサシン」などの強烈なコンボを同時に完成させられる最大のアドバンテージ。
*   **代表タグ**: `カウンターピック` `コンボピック` `フレックス` `デナイアル`

### 4〜5手目（先攻 4th & 5th Pick）
*   **求められる性能**: 「編成の完成」＋「相手のラストピック（6手目）の警戒」
*   **考え方**: 相手は最後に6手目を単独で選べるため、4-5手目で不用意に隙（投げ対策なし、アサシン対策なし等）を作ると、6手目で一気に破壊される。相手のラストピックを封じるキャラを入れるのが鉄則。
*   **代表タグ**: `弱点ケア` `補完ピック` `カウンターピック`

### 6手目（後攻 6th / Last Pick）
*   **求められる性能**: 「相手3体に対する圧倒的な有利（ハードカウンター）」
*   **考え方**: ドラフト最大の特権。相手はもうキャラを変えられないため、相手の構成に刺さるキャラを選べば100%の勝率を狙える。
*   **代表タグ**: `ラストピック特化`

## 3. タグ機能への組み込み候補（厳選案）

もし現在の「役割・ドラフト」カテゴリをドラフト目線でさらに強化する場合、以下の構成が実用的でおすすめです：

1. **先出し安定**（1st向け：汎用・無難）
2. **後出し特化**（6th向け：ラストピック完封）
4. **カウンター枠**（2nd〜5th向け：特定の相手潰し）
5. **弱点ケア**（4th〜5th向け：アンチ迎撃・防衛）
6. **BAN推奨**（BAN用：環境・マップ破壊キャラ）
