# 重力反転コネクトフォー (Gravity Connect Four) 仕様・ルール定義書

本ドキュメントは、「重力反転コネクトフォー」の完全なゲームルール、状態遷移、物理シミュレーション、および勝敗判定ロジックを正確に定義したものです。

---

## 1. 基本定義と座標系

### 盤面構造
- **グリッドサイズ**: 7行 × 7列（計49マス）。
- **座標系**: `(r, c)` で表す。
  - 行インデックス `r`: `0`（最上段）〜 `6`（最下段）
  - 列インデックス `c`: `0`（最左列）〜 `6`（最右列）
- **各マスの状態**: `null`（空マス）、`"red"`（先手 / プレイヤー）、`"yellow"`（後手 / AI）

### プレイヤーおよび手番定義
- **プレイヤー（赤 / `red`）**: ユーザー操作
- **AI / CPU（黄 / `yellow`）**: コンピュータ操作
- **手番選択**: 対局開始前（1手目を着手する前）に、プレイヤーが**先攻（赤が初手）**または**後攻（黄が初手）**を選択可能。デフォルトは先攻。1手目が打たれた時点で対局終了まで手番選択は固定（ロック）されます。

## 2. 重力システムと物理スライド

重力は盤面全体に一様に働き、石の着地点および反転時の全石移動を支配します。

### 重力の4方向と方向ベクトル
重力方向は 4 つ存在し、方向ベクトル `(dr, dc)` で定義されます。

| インデックス | 方向名 (`id`) | ベクトル `(dr, dc)` | 石が落ちる先 | 投入口（重力の上流） |
| :---: | :---: | :---: | :---: | :---: |
| **0** | **下 (`down`)** | `(+1, 0)` | 最下行 (`r=6`) | 最上行 (`r=0`, 任意の列) |
| **1** | **右 (`right`)** | `(0, +1)` | 最右列 (`c=6`) | 最左列 (`c=0`, 任意の行) |
| **2** | **上 (`up`)** | `(-1, 0)` | 最上行 (`r=0`) | 最下行 (`r=6`, 任意の列) |
| **3** | **左 (`left`)** | `(0, -1)` | 最左列 (`c=0`) | 最右列 (`c=6`, 任意の行) |

### 通常着手（石の投入）
1. プレイヤーまたはAIは、重力の上流から進入可能な任意の列（または行）に石を投入する。
2. 石は重力ベクトル `(dr, dc)` に従い、盤面の境界または既存の石に突き当たるまで直進して着地する。
3. 着地点が確定すると、そのマスに石が配置される。

### 全石の一斉スライド（重力反転時）
重力が切り替わった場合、盤面上に存在するすべての石が新しい重力ベクトル `(dr, dc)` に向かって一斉に滑落する。
- **独立ラインスライド**: スライドは重力方向に平行な各ライン（上下重力なら各列、左右重力なら各行）ごとに完全に独立して詰められます（ライン間で石が移動することはありません）。
- **順序**: 重力の下流側にある石から順に詰めて配置されます（同一ライン内の石同士の相対順序は崩れません）。

## 3. 自動重力反転サイクル

- **巡回順序の初期状態**: **時計回り (`isClockwise = true`)** で開始します（下 → 右 → 上 → 左 → 下...）。
  - **時計回り (`isClockwise = true`)**: 下 (`down`, index 0) → 右 (`right`, index 1) → 上 (`up`, index 2) → 左 (`left`, index 3) → 下...
  - **反時計回り (`isClockwise = false`)**: 下 (`down`, index 0) → 左 (`left`, index 3) → 上 (`up`, index 2) → 右 (`right`, index 1) → 下...
- **即時転換後の巡回起点**: 即時転換スキルで指定された方向が新しい「現在の重力方向」となり、以降の自動反転はそこから `isClockwise` の巡回順に従って進みます。
- **反転トリガー**:
  - **両プレイヤー合わせて3手（通常配置またはスキル発動）打つごと**に自動反転する。
  - カウントダウン（残り手数 `movesLeft`）は初期値 `3` で開始し、1手ごとに `-1` される。
  - 周期反転スキルの発動によって `movesLeft === 0` になった場合も、**反転後の新しい巡回順に従って直ちに自動反転が発生**し、全石の一斉スライドと勝敗判定（仕掛け人ルール適用）が行われます。
  - `movesLeft === 0` になった瞬間、自動重力反転が発生し、全石が一斉スライドする。
  - スライド完了後、`movesLeft` は `3` にリセットされる。

## 4. MP（エネルギー）と3大スキルシステム

各プレイヤーはMPを管理し、通常着手の代わりにスキルを発動できる。

### MP仕様
- **初期MP**: `8` MP（満タン開始）
- **最大MP**: `8` MP
- **MP獲得**: **通常着手で石を1つ配置するごとに `+1` MP** 回復する（最大8まで）。
- **スキル発動時**: 石は配置しないため、MP回復は行われない。

### 3大スキルの効果とコスト

| スキル名 | 消費MP | 効果と状態遷移 |
| :--- | :---: | :--- |
| **周期反転** (`reverse`) | **2 MP** | 重力の巡回順序を反転させる（`isClockwise = !isClockwise`）。石の移動は発生しない。手番を終了する。 |
| **重力前進** (`forward`) | **4 MP** | 手数を待たずに、現在の周期に従って**即座に次の重力方向へ移動し、全石を一斉スライド**させる。残り手数は `3` にリセットされ、手番を終了する。 |
| **即時転換** (`shift`) | **8 MP** | 巡回順序を無視し、**指定した任意の方向（現在の方向を除く残り3方向）へ即座に重力を変更し、全石を一斉スライド**させる。全MP（8 MP）を消費する。残り手数は `3` にリセットされ、手番を終了する。 |

## 5. 1ターンの厳密な実行フロー

各プレイヤーの手番は以下の順序で厳密に処理される。

```text
[手番開始]
   │
   ├─► 【通常着手】: 空いている有効マスへ石を落とす
   │       │
   │       ├─► 落下・着地 ──► 対象プレイヤーの MP を +1 (最大8)
   │       ├─► 【勝敗判定 1】（四目並びチェック） ──► 勝者ありならゲーム終了
   │       ├─► 残り手数減算: movesLeft = movesLeft - 1
   │       └─► movesLeft === 0 の場合:
   │               ├─► 重力を次の方向へ変更
   │               ├─► 全石一斉スライド
   │               ├─► 【勝敗判定 2】（四目並びチェック） ──► 勝者ありならゲーム終了
   │               └─► movesLeft = 3 にリセット
   │
   └─► 【スキル発動】: MPを消費してスキルを実行
           │
           ├─► スキル効果の適用（周期反転 / 重力前進 / 即時転換）
           ├─► 重力移動を伴うスキル（前進・転換）の場合:
           │       ├─► 全石一斉スライド
           │       ├─► 【勝敗判定 3】（四目並びチェック） ──► 勝者ありならゲーム終了
           │       └─► movesLeft = 3 にリセット
           └─► 周期反転スキルの場合:
                   ├─► isClockwise 反転
                   ├─► 残り手数減算: movesLeft = movesLeft - 1
                   └─► movesLeft === 0 なら自動反転処理へ
   │
[手番終了 ──► 相手プレイヤーへ手番交代]
```

## 6. 勝敗判定アルゴリズムと重要規定

### 勝利条件
盤面上の**縦・横・斜め（右下・右上）のいずれかの直線上に、同色の石が4つ以上連続**して並んだ場合、その色のプレイヤーの勝利となる。
- 全88本の4連ライン（横28本、縦28本、斜め32本）を走査して判定する。

### 同時成立時の優先権（仕掛け人ルール / Initiator Rule）
重力反転（自動反転、重力前進、即時転換）による全石スライドの結果、**赤（プレイヤー）と黄（AI）の両方の4連が同時に成立した場合**：
- **その重力変化を引き起こした側（現在手番のアクティブプレイヤー）の勝利**とする。
- 理由: 自らの着手またはスキルによって連鎖と局面変化を起こしたプレイヤーの戦略的イニシアチブを評価するため。

### 引き分け（ドロー）条件と判定順序
盤面の全49マスがすべて石で埋まり、どちらのプレイヤーも4連を達成していない場合に引き分けとなります。
- **最後の1マスで4連が完成した場合**: 盤面が埋まったことよりも**四目並び（勝利）の成立が優先**され、そのプレイヤーの勝利となります（引き分けにはなりません）。
