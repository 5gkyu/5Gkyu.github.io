ブロスタ（Brawl Stars）のガチバトル（Ranked）および競技シーン（Esports）におけるドラフト手番・役割・立ち回り・相性対策・自衛耐性・スキル特性を整理したタグ一覧です。

## 1. ドラフト

マップ上での配置や、ドラフト（BAN/PICK）時の立ち回り・ピック順を表す最重要タグ。

| タグ名 | 説明 | 代表的なキャラクター例 |
| :--- | :--- | :--- |
| **1手目** | 先攻初手（1st）。相手の出方が見えない段階でも絶対に腐らない万能・環境最強枠 | コレット、ジーン、マックス、クランシー、ベリー |
| **2-3手目** | 後攻初手（2nd/3rd）。相手初手をメタりつつ、2体コンボ（シナジー）を成立させる枠 | サージ、メイジー、バイロン、チェスター、キット |
| **4-5手目** | 先攻最終（4th/5th）。チームの不足を補い、相手の6手目（奇襲）を迎撃・警戒する枠 | ゲイル、シェリー、オーティス、ブロック、ルー |
| **6手目** | 後攻単独ラスト（6th）。相手3体にアンチがいない状況で出し、単体で完封する枠 | モーティス、エドガー、エリザベス、ドラコ、チャック |
| **ミッド** | マップ中央を担当し、射程やエリア支配力で戦況をコントロールする枠 | エリザベス、ジーン、ベル、バイロン |
| **サイド** | 左右のレーン戦で対面に勝ち、相手を押し込む枠 | コレット、シェリー、マックス、チェスター |
| **キャリー** | 圧倒的な火力や打開力でチームを勝利に導く主軸・エース枠 | クランシー、ファング、モーティス、エリザベス |
| **先出しで強い** | 相性差が小さく、相手にカウンターされにくい汎用性の高い枠 | コレット、ジーン、マックス、ベリー |
| **後出しで強い** | 相手の編成に特定の弱点がある時に刺すラストピック向け枠 | エドガー、ドラコ、モーティス、エリザベス |

## 2. ロール

キャラクターの根本的な戦い方・プレイスタイルを表すタグ。

| タグ名 | 説明 | 代表的なキャラクター例 |
| :--- | :--- | :--- |
| **タンク** | 高HPを活かして前線を押し上げ、敵の攻撃を受け止める | ブル、エル・プリモ、フランク、ローサ、アッシュ |
| **アサシン** | 高い機動力や奇襲能力で敵の後衛（スナイパー・投げ）を暗殺する | モーティス、クロウ、レオン、エドガー、ファング、リリー |
| **スナイパー** | 遠距離から一方的にプレッシャーをかける単発・精密射撃キャラ | エリザベス、マンディ、アンジェロ、ブロック、ベル |
| **シューター** | 中〜長距離から連射・弾幕で継続して圧力をかける射撃キャラ | コルト、リコ、ローラ、パール |
| **投げ** | 壁越しに安全圏から放物線状の攻撃を行える投擲キャラ | ダイナマイク、ティック、スプラウト、ラリー＆ローリー |
| **サポート** | 味方へのバフ（加速・シールド）やウルト供給などで支援する | マックス、ラフス、ガス、キット |
| **ハイブリッド** | 形態変化や複数の戦闘スタイルを使い分ける変則キャラ | メグ、チェスター、ボニー、チャック |

## 3. タイプ

攻撃の有効射程や弾の性質・当たり方に関するタグ。

| タグ名 | 説明 | 代表的なキャラクター例 |
| :--- | :--- | :--- |
| **長射程** | 遠距離・スナイパーライフル級の長い間合い | エリザベス、マンディ、アンジェロ、コルト、ベル、ブロック |
| **中射程** | バランスの取れた標準的な間合い | シェリー、マックス、サンディ、ボウ |
| **短射程** | 接近戦を得意とする間合い | ジャッキー、メイジー、チェスター、ブル |
| **単発** | 1発の弾を射出してダメージを与える攻撃タイプ | エリザベス、マンディ、ビー、ブロック、アンジェロ |
| **連射** | 複数弾を連続して発射する攻撃タイプ | コルト、リコ、ローラ、パール、グリフ |
| **複数攻撃** | 範囲・貫通・連鎖など、一度に複数の敵や召喚物を巻き込める攻撃 | スパイク、ポコ、タラ、ジェシー、ベル、エムズ |

## 4. メタ

特定の敵タイプに対して圧倒的に有利を取れるアンチ性能を表すタグ。

| タグ名 | 説明 | 代表的なキャラクター例 |
| :--- | :--- | :--- |
| **タンク対策** | 割合ダメージや近接超火力で高HPタンクを容易に処理する | コレット、シェリー、グリフ、サージ、メイジー |
| **投げ対策** | 壁を飛び越えて接近したり、壁を破壊して投擲キャラを無力化する | モーティス、エドガー、ブロック、ストゥー |
| **スナイパー対策** | 高速移動、シールド、奇襲でスナイパーの射程を潰す | ナーニ、レオン、マックス、アサシン全般 |
| **アサシン対策** | ノックバック、スタン、スローで突進してきたアサシンを迎撃する | メイジー、ジーン、シェリー、ゲイル、サージ |
| **召喚物対策** | 貫通や連鎖攻撃で敵のタレット・ペット・子分を逆利用する | ペニー、ジェシー、ベル |

## 5. 自衛

敵アサシンやタンクの急襲・飛び込み（ダイブ）を防ぎ、生き残る・返り討ちにする自衛手段に関するタグ。

| タグ名 | 説明 | 代表的なキャラクター例 |
| :--- | :--- | :--- |
| **エスケープ** | ジャンプやワープ、瞬間移動で敵の急襲から即座に間合いを取って離脱する | エリザベス（ウルト）、ブロック（ガジェット）、サージ、グレイ、リリー |
| **バリア** | シールドやダメージ大幅軽減、無敵化で敵の瞬間火力を耐え凌ぐ | ガス、エドガー、ナーニ、ローサ、クロウ |
| **ノックバック** | 接近してきた敵を弾き飛ばして間合いを離し、突撃を中断させる | ジーン、ゲイル、ビビ、シェリー、メイジー |
| **スタン** | 飛び込んできた敵を一定時間気絶させて行動不能にする | フランク、バズ、ダイナマイク、メイジー |
| **スロー** | 接近してくる敵の移動速度を低下させて距離を維持する | クロウ、スパイク、メイジー、ルー、ゲイル |
| **攻撃封印** | 接近された際に相手の通常攻撃・ウルトを封印して無力化する | オーティス、コーデリアス |
| **瞬間火力** | 懐に飛び込まれた瞬間にゼロ距離で超大ダメージを叩き込み返り討ちにする | シェリー、グリフ、チェスター、エリザベス |

## 6. ユーティリティ

特殊な能力や特定モード・ギミックへの適性に関するタグ。

| タグ名 | 説明 | 代表的なキャラクター例 |
| :--- | :--- | :--- |
| **回復** | 自身または味方のHPを回復・延命する能力 | ポコ、バイロン、パム、ベリー、エドガー、ガス |
| **壁草破壊** | 壁や障害物、草むらを破壊して射線を通す能力 | ブロック、コルト、ブル、フランク、グリフ |
| **索敵** | 草むらの中の敵を発見・可視化する能力 | タラ、ボウ、ビジョンギア持ち |
| **透明化** | 姿を消して奇襲や安全な離脱を行う能力 | レオン、サンディ、キット |
| **高機動力** | ダッシュやジャンプ、ワープで瞬時に位置を変える能力 | モーティス、サージ、ブロック、グレイ |
| **召喚物** | タレットやペットなどを設置・召喚して数的有利を作る能力 | ジェシー、ニタ、ペニー、ミスターP |
| **金庫削り** | 強奪の金庫やオブジェクトへのダメージ効率・削り速度が圧倒的なキャラ | チャック、コレット、ブル、ジェシー、クランシー |
| **金庫防衛** | 強奪の自軍金庫や拠点を守り、敵の突撃や削りを阻止する能力が高いキャラ | コレット、オーティス、ゲイル、ルー、シェリー |
