色に名前をつけるということ
2026.05.17 考察

「この青は何色ですか」と問われたとき、あなたはなんと答えるだろう。コバルトブルー、スカイブルー、セルリアン、ターコイズ。あるいは「空色」や「瑠璃色」。そして今やわたしたちには、#4169E1 という選択肢もある。

色に名前をつけること——それは人間が太古から続けてきた、きわめて不思議な行為だ。光の波長という物理現象を言語に翻訳し、他者と共有しようとする試み。その積み重なりが文化になり、時代を越えて変化してきた。現代のWebデザインという文脈において、その行為はどんな意味を持つのか。今日はそのことを、少し遠回りしながら考えてみたい。

言語が色を「作る」

色は光の連続したスペクトルである。虹の色は本来、どこで区切れているわけではない。にもかかわらず、日本語話者は「赤・橙・黄・緑・青・藍・紫」と7色を認識し、英語話者は "red, orange, yellow, green, blue, indigo, violet" と数える。これは偶然ではなく、言語が知覚そのものに影響を与えているという仮説がある。

言語学の分野で「サピア＝ウォーフ仮説」と呼ばれるこの考え方は、「言語の構造が話者の思考や認知に影響を与える」というものだ。色に関して言えば、その言語に色名が多いほど、話者はより細かく色の差異を認識できる——という傾向が実験でも示されている。

わたしの言語の限界は、わたしの世界の限界を意味する。

ウィトゲンシュタインのこの一節は、しばしば誤解される。「言語がなければ概念が存在しない」と読まれがちだが、彼が言いたかったのはより繊細なことだ——語りえないものについては、沈黙しなければならない。色の名前を持たないことは、その色を感じないことではない。ただ、それについて語れないだけである。

カラーコードという哲学

Webの世界では、色は16進数の記号で表される。

:root { --clr-sage: #9AB08F; /* セージグリーン 穏やかさ・自然 */ --clr-peach: #EEAFA1; /* ピーチ ぬくもり・親しみ */ --clr-dusty-blue: #92B5BC; /* ダスティーブルー 静けさ・知性 */ --clr-cream: #FBF6EA; /* クリーム やわらかさ・余白 */ --clr-brown: #6A564A; /* ブラウン 落ち着き・信頼 */ }

これはこのサイト「Halcyon」で定義しているカラーパレットだ。一見すると無機質な記号の羅列だが、よく見ると面白いことに気づく。#9AB08F というセージグリーンは、その数字が穏やかさを「持っている」わけではない。しかし、画面に出力された瞬間、それは確かに穏やかさを「持つ」ものになる。

カラーコードは「色そのもの」ではなく、ディスプレイへの命令文です。モニターの種類・キャリブレーション・周囲の光によって、同じコードでも見え方は変わります。

つまりカラーコードとは、「この光を出力せよ」という命令であり、出力された結果として人間が受け取る「感覚」は、コードが直接持っているものではない。この非対称性——記号と、記号が呼び起こす感覚のズレ——は、記号論が長年議論してきた問いそのものだ。

色名という文化の蓄積

日本の伝統色の名前には、名付けた時代の感性が剔まれている。単に色を識別するための記号ではなく、その色を見た人間の詩的な直観が言語になったものだ。

「萌黄」「瑠璃色」「撒子色」——名前そのものが詩であり、文化の記憶だ。植物、空、花……自然からの借り物の言葉が、色に物語を与える。曖昧さが豊かさになる。

#B0CA71、#2E5894——数字は厳密で、世界中の誰でも同じ色を再現できる。しかしその記号からは、文化の記憶は何も伝わらない。

日本の色名の多くは植物から来ている。植物染料が日常にあった時代、色と自然は切り離せなかった。名前を聞いただけで風景が浮かぶような、詩的な命名の文化がある。

萌黄（もえぎ） 若草色 撫子色（なでしこいろ） 桃色 草色

「萌黄（もえぎ）」は春に芽吹く若草の色。「撫子（なでしこ）」は花の名前そのものが色になった。源氏物語など平安文学にも多くの色名が登場し、貴族たちが重ね着の配色に込めた美意識の痕跡が、名前の中に生きている。

天然の鉱物や空・海の色も、日本の色名の豊かな源泉だ。宇宙的なスケールや稀少性が色名に「格」を与えている。

瑠璃色（るりいろ） 水色 青磁色（せいじいろ） 勝色（かちいろ）

「瑠璃（るり）」はラピスラズリという鉱石の和名。深く神秘的なその青は、古来から貴重品とされてきた。「勝色」は濃い藍色で、武士が戦に臨む際に縁起を担いで用いたとされる。色の名前に、人々の祈りや信仰が宿っている。

色名は過去のものだけではない。現代のデザインやファッションの文脈でも新しい色名は生まれ続けている。

セージグリーン テラコッタ ダスティーブルー ミルクティーブラウン

「セージグリーン」「テラコッタ」「ミルクティーブラウン」——これらはインテリアやファッションの文脈で広まった現代の色名だ。英語由来のものが多く、カタカナ表記が「ちょっとおしゃれ」なニュアンスを帯びさせる。言語の変化は色名にも表れている。

見ているものは同じか

さらに根本的な問いがある。あなたが「赤」と呼ぶものと、わたしが「赤」と呼ぶものは、本当に同じ感覚なのだろうか。

ねえ、「赤」って感じたとき、頭の中にどんな色が浮かぶ？

え、普通に赤でしょ。信号の赤とかポストの赤とか……。

でも「感じてる色」は同じかな、ってこと。わたしが見てる赤と、あなたが見てる赤が、脳の中で同じ体験かどうか確かめようがなくない？

……確かに。その問いって哲学でなんか名前あったっけ。

「クオリア」って呼ばれてる。感覚の主観的な質のこと。原理的に証明できないんだよね。

「クオリア（qualia）」とは、意識のある存在が持つ主観的な感覚の質のことだ。赤を見たときの「あの感じ」、コーヒーを飲んだときの「あの苦み」——それらが自分以外の人に同じように感じられているかどうかは、原理的に確かめることができない。

カラーコード #FF0000 は万人に同じ光を出力するが、その光を受け取った脳が作り出す「赤さ」の体験は、もしかすると人によって異なるかもしれない。だとしたら、わたしたちが「同じ色の名前」で会話できていることは、かなり奇跡的なことではないだろうか。

Webデザインと色の命名

こうした背景を踏まえると、Webデザインにおける色の扱い方も少し違って見えてくる。デザイナーが色に名前をつけるとき——--clr-sage、--color-primary、--accent-warm——それは単なる変数名ではない。その色に込めた意図と感情を、チームや未来の自分に伝えるための言語だ。

「この色はどんな感情を呼び起こしたいのか」を先に決める。色を選んでから名前をつけるのではなく、役割から逆算する。「穏やかさ・安心感」なら彩度を抑えたグリーン系、「ぬくもり・親しみ」なら茶系やサーモンピンクが候補に浮かぶ。 color1、color2 のような無意味な名前は避ける。--clr-sage（セージ：薬草・癒し）のように、その色のニュアンスが名前から伝わると、コードを読むだけで色が想起できる。変数名はコメントである、という意識が大事だ。 名前だけでは不十分で、「いつ使うか」のルールが必要だ。「アクセントカラーは強調要素にのみ使う」「背景色は白とクリームの2種類に限定する」といった制約が、デザインの一貫性を生む。 どんなに理論的に正しくても、実際の画面で見るまでわからないことがある。作ったカラーパレットを実際のコンポーネントに当てはめ、違和感があれば名前ごと見直す勇気を持つ。

色には文化差があります。たとえば「白」は日本では喪に服す場でも用いられますが、西洋では純粋さの象徴です。グローバルなサービスを作る際は、ターゲット地域の色のコンテキストを確認しましょう。

名前をつけることの意味

色に名前をつけることは、世界を分節化することだ。連続した光のスペクトルに境界線を引き、「これ」と「あれ」を区別する行為。その行為が積み重なって文化になり、言語になる。

Webの世界では、その境界線がピクセルとコードで引かれる。#9AB08F という記号が「セージグリーン」という名前を得た瞬間、それは単なる数字ではなく、ある感情の住所になる。

だから色に名前をつけることは、単なる管理の都合ではない。それは、世界をどのように見るか——あるいはどのように見せたいか——の表明だ。あなたがデザインで選ぶ色の名前には、あなた自身の感性と哲学が宿っている。

この記事では「色を見る」ことを自明のものとして書きましたが、実際には色覚の多様性があります。日本人男性の約5%、女性の約0.2%が、何らかの色覚多様性を持つとされています。

Webデザインにおいては、色だけで情報を伝えないこと（形・テキスト・アイコンを併用する）が重要です。色名の哲学を楽しみながら、アクセシビリティへの配慮も忘れずにいたいところです。
