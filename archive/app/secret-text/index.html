特殊・透明文字コピー

画面表示やシステムに特殊な影響を与えるUnicodeの文字をカテゴリ別にまとめました。用途に応じて使い分けられるよう、代表的なものをリストアップしています。

1. 見えない・幅を持たない文字（ゼロ幅文字）

画面上には表示されませんが、システムの挙動（改行や単語の区切りなど）をコントロールするために裏で働く文字です。

ハングルフィラー (Hangul Filler) U+3164
透明文字の代表格。空白のように見えますが、文字として認識されるため名前の未入力回避などによく使われます。
点字の空白 (Braille Pattern Blank) U+2800
点が1つもない点字。システムに「空白（スペース）」として削除されにくいため、透明文字の代用として優秀です。
ゼロ幅スペース (Zero Width Space) U+200B
幅が完全にゼロのスペース。見た目は変わりませんが、システムに「ここで改行してもOK」と伝えます。
単語結合子 (Word Joiner) U+2060
ゼロ幅スペースの逆。この文字を挟んだ単語同士は「絶対にここで改行させない」という強い結びつきを持ちます。
ゼロ幅接合子 (Zero Width Joiner / ZWJ) U+200D
隣り合う文字（主に絵文字やアラビア文字）を合体させるボンド。例：「👨」+ ZWJ +「🍳」＝「👨‍🍳」
ゼロ幅非接合子 (Zero Width Non-Joiner) U+200C
ZWJの逆。本来くっついて表示される文字同士を、強制的に離して（独立させて）表示させます。
ネクストライン (Next Line / NEL) U+0085
システムに「次の行へ移動する」ことを指示する制御文字です。通常の改行（LFやCR）とは異なるため、一部のシステムで特殊な挙動を引き起こすことがあります。

2. テキストの進行方向・レイアウトを操作する文字

テキストの流れる方向を強制的に変えたり、1文字で異常なスペースを取ったりする文字です。悪用されることも多いため、多くのシステムで警戒されています。

右から左へのオーバーライド (Right-To-Left Override) U+202E
この文字以降のテキストを強制的に右から左へ反転させます。（例：あいう → ういあ）
左から右へのオーバーライド (Left-To-Right Override) U+202D
上記の逆。反転したテキストを通常の左から右への流れに戻す際に使われます。
アラビア語の合字 (Arabic Ligature Bismillah) U+FDFD
「﷽」。神の御名において、という長いフレーズを1文字に圧縮したもの。1文字なのに異常に横幅が長いため、UI破壊によく使われます。
ソフトハイフン (Soft Hyphen) U+00AD
普段は透明ですが、行の右端で単語が途切れて改行される時だけ「-（ハイフン）」として姿を現す忍者テキストです。

3. 文字を装飾・侵食する文字（ダイアクリティカルマーク）

前の文字に点や線を「後付け」するための文字です。仕様上、無限に重ね掛けできるため、文字化け（Zalgo Text）を引き起こす原因になります。

合成用マクロン (Combining Macron) U+0304
前の文字の上に横線を引きます。（例：a + ̄ = ā）
合成用ロングソリドゥス (Combining Long Solidus) U+0338
前の文字に斜線を引いて打ち消します。（例：A + ̸ = A̸）
合成用下部チルダ (Combining Tilde Below) U+0330
前の文字の下に波線を引きます。（例：A + ̰ = A̰）
