# 無料 画像生成AI デモ

APIキー不要・無料で使える `Pollinations` を利用した最小構成のWebデモです。

## 使い方

1. `index.html` をブラウザで開く
2. プロンプトを入力
3. 必要なら幅・高さ・Seedを調整
4. `生成する` を押す

## ファイル構成

- `index.html` : UI
- `style.css` : 見た目
- `script.js` : 画像生成URLの組み立てと表示

## メモ

- 完全無料で試せます（2026-03 時点）
- 外部サービス仕様は将来変更される可能性があります
- 生成結果の利用時は各サービスの利用規約を確認してください
