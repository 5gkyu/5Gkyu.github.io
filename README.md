# 5Gkyu's Homepage / Halcyon Web

ようこそ。
ここは、「きゅー（[5Gkyu](https://github.com/5Gkyu)）」の個人のホームページであり、様々な自作Webアプリ、UIコンポーネント、ゲーム、そして実験的なコードを保管するためのコード置き場（リポジトリ）です。

## 🕊️ Halcyon - The Concept & Worldview

このサイト全体のデザインや空気感は、オリジナルキャラクターグループ **「Halcyon（ハルシオン）」** の世界観をベースに設計されています。

Halcyonとは、Akari、Becky、Charlotte、Dulcie、Esmé、Fūka という6人の少女たちからなるグループです。彼女たちはそれぞれ違う不安や不器用さを抱えていますが、無理に干渉しすぎることはなく、まるでパズルのピースのように互いの空白をそっと補い合っています。

> **"寛容な共鳴" と "温かい沈黙"**
> 
> 言葉を多く交わさずとも、ただそこにいるだけで成立する穏やかな時間。
> 誰も無理をせず、互いの距離感を尊重しあえる関係性。

このサイトのUIデザイン（**Halcyon UI**）は、彼女たちの持つ「優しさ」「ノスタルジー」「静かな安心感」をWeb上で表現する試みです。
クリーム色やセージグリーンといった自然で落ち着いた色彩、角の丸み、フワッと現れる柔らかなアニメーションはすべて、このHalcyonのストーリーとリンクしています。

## 📦 コンテンツ

このリポジトリには、主に以下のようなコンテンツが保管されています。

- **App & Tools (`/archive/app/`)**: 画像のコラージュ作成、画像圧縮、PDF変換などの便利ツール。
- **Play (`/archive/play/`)**: 自作のロジックパズルゲームなどの遊べるコンテンツ。
- **Halcyon UI Components (`/components/`)**: Halcyonの世界観を体現した、再利用可能なWebコンポーネント群とデザインリファレンス。
- **Note (`/archive/note/`)**: タイポグラフィやデザインに関する個人的な備忘録・コラム。

## 🔧 開発について

- **Vanilla HTML / CSS / JS**: このサイトの多くは、フレームワークに依存せずVanillaなWeb標準技術（Custom Elements等）を用いて構築されています。
- **デザインファースト**: 機能を詰め込むのではなく、「触っていて心地よいか」「Halcyonらしさがあるか」という美学・手触りを大切にしています。
