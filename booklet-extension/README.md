# Halcyon ブックマークレットランチャー（Chrome拡張機能）

GitHub（`5gkyu.github.io`）上のブックマークレット定義と自動同期し、**X（Twitter）やGitHubなど、CSPセキュリティ制限の厳しいWebサイト上でも確実にブックマークレットを実行できる**拡張機能です。

拡張機能本体は一度インストールすれば更新作業は一切不要です。  
今後は **GitHub上の `bookmarklets-data.js` を更新するだけで、自動的に新しいブックマークレットが反映** されます。

---

## 導入手順（約30秒）

### ステップ 1: Chromeの拡張機能画面を開く
1. Google Chrome（またはEdge / Brave等）を開きます。
2. アドレスバーに以下を入力してEnterキーを押します：
   ```text
   chrome://extensions/
   ```

### ステップ 2: デベロッパーモードをONにする
1. 画面右上にある **「デベロッパーモード」** のスイッチを **ON** にします。

### ステップ 3: 拡張機能フォルダを読み込む
1. 画面左上に出現する **「パッケージ化されていない拡張機能を読み込む」** ボタンをクリックします。
2. このフォルダを選択します：
   ```text
   mainpage/booklet-extension
   ```
3. 「Halcyon ブックマークレットランチャー」が追加されます。

### ステップ 4: ツールバーにピン留めする（便利）
1. ブラウザ右上のパズルピースアイコン（拡張機能メニュー）をクリックします。
2. 「Halcyon ブックマークレットランチャー」の横にある **ピン留めアイコン** をクリックすると、ツールバーに常時表示されます。

---

## 使い方

1. 任意のWebサイト（YouTube、X、GitHub、Googleなど何でもOK）を開きます。
2. ツールバーのランチャーアイコンをクリック（またはキーボードで **`Ctrl + Shift + L`**）。
3. ポップアップ画面が開き、ブックマークレット一覧が表示されます。
4. 実行したいツールをクリックするだけで、現在開いているページで即座に実行されます。

---

## GitHubの更新が反映される仕組み

- ポップアップを開くたびに、裏側で自動的にGitHub（`https://5gkyu.github.io/archive/other/booklet/bookmarklets-data.js`）から最新データを取得します。
- 新しいブックマークレットを追加したいときは、GitHub上の `bookmarklets-data.js` に項目を追加して `git push` するだけで完了です。
- ポップアップ右上の **更新ボタン（回転アイコン）** を押すことで、いつでも手動で最新データに更新することもできます。
